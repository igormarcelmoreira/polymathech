# Forma de Organização

A forma da qual o time decidiu se organizar foi com base em "squads", ou seja, times dividindo o grupo inteiro, onde cada time tem um número balanceado de AGES I, II, III. Os AGES III e IV ficaram responsaveis por gerenciar todos os times e estabelecer as atividades que cada Squad ficou responsavel.

# Distribuição das atividades de cada Sprint

Para distribuir as atividades, foi levado em conta que cada Squad teria que ser responsavel por atividades relacionadas tanto do frontend, quanto do backend.
