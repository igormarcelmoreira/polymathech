# Bem vindo à Wiki do projeto <Nome do projeto>

![equipePoly](uploads/7fcced8faad11ce5f13309b2eb3d0614/equipePoly.jpg)

#### Objetivo do Projeto 

Desenvolver uma inovadora plataforma web dedicada aos estudos direcionados, oferecer uma gama completa de ferramentas facilitadoras e orientações profissionais. Proporcionar uma experiência de aprendizado focada, contextualizar as diferentes carreiras de maneira envolvente, autêntica e acessível a todos os públicos, por meio de uma linguagem jovial, clara e objetiva.
